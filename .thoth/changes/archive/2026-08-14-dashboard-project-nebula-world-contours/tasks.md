## Authoring contract

Tasks are sequential because the same prepared-graph, runtime overlay, React composition, CSS hit-testing, and browser-harness surfaces are refined across all three stories. The implementation writer marks a task complete only after its stated verification evidence exists.

## MVP scope

US1 is the MVP: project-hierarchy Universe renders one organic contour per visible project from its owned constellation-core positions, without phantom center contours, static decorative project glows, detached labels, or boxed core-label clutter. It is independently complete when pure geometry tests and the mounted project-Universe contour diagnostics pass.
