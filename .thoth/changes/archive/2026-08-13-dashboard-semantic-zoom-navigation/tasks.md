# Tasks: Bounded Semantic Zoom Navigation

## Authoring contract

Every executable task owns one mutable repository path, names its FR/SC coverage, and ends with observable verification. Work is ordered in vertical red→green slices. Later mounted tasks consolidate already-green behavior; they do not substitute for the focused red test that precedes each production surface.

US2 is the first independently testable increment: the existing atlas route accepts an additive semantic-zoom Community presentation and returns one deterministic 6–12-region, 80–180-memory, at-most-450-relationship working set with exact source accounting, while omitted or complete presentation retains current pagination.
