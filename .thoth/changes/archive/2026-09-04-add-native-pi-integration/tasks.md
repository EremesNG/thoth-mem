# Tasks: Native Pi Integration

## MVP scope

US1 is independently testable when `thoth-mem setup pi` plans, installs,
verifies, repeats, replaces only receipt-owned provenance, and rolls back against
a disposable Pi manager. The useful product MVP adds US2: the native extension
loads with the exact six shared tools through one MCP child. Each behavior slice
below follows an immediate red-to-green order.
