# Tasks: Guided Cosmos Dashboard Experience

## Authoring contract

Task IDs are sequential across the complete change. Every behavior-changing slice starts with a failing public-seam test, receives only enough implementation to pass, and is simplified only after the accepted behavior is green. Root is the sole implementation writer; independent Oracle review and verification remain read-only.

## MVP scope

US1 is the first independently testable story: a populated observatory renders through the local GPU engine, supports focus/camera/expansion transitions, preserves every pointer and keyboard command, pauses cleanly, and honors reduced motion. Completion evidence is the focused cosmos graph unit suite plus the mounted real-browser graph suite.
