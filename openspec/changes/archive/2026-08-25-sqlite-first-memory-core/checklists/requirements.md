# Requirements checklist: SQLite-first persistent memory core v2

**Activation reason**: The change intentionally replaces the database lineage and public runtime semantics, deletes load-bearing retrieval/graph/dashboard surfaces, packages three host integrations, imports user-owned legacy data, and establishes benchmark promotion gates. Contract or migration ambiguity has a high failure cost even though the repository is experimental.

## Initial validation

- [x] CHK001 [Completeness] Do US1–US7 cover developer, coding-agent, maintainer, and operator actors plus start/resume, capture, correction/failure history, offline recall, migration, evaluation, installation, degradation, and rollback flows? Evidence: every actor/flow appears in a user story with an independent test and Given/When/Then scenarios.
- [x] CHK002 [Clarity] Does every FR-001–FR-063 have one normative MUST/SHALL interpretation and exactly one inspected canonical delta marker? Evidence: the Full SDD specify validator passes and all renamed/modified/removed titles match the current canonical requirements.
- [x] CHK003 [Consistency] Do stories, FRs, assumptions, dependencies, and out-of-scope boundaries agree on SQLite/FTS5 authority, optional projections, six tool names with breaking v2 semantics, three hooks+MCP+Skills plugins, and no first-product dashboard/HTTP/graph? Evidence: no section promises a required model/service, compatibility shim, graph action, or passive activity stream.
- [x] CHK004 [Measurability] Is every SC-001–SC-014 classified and objectively observable without using popularity or current benchmark claims as proof? Evidence: buildable SCs name tests/artifacts/counts/bounds and outcome SCs declare numeric token/quality/promotion thresholds; specify validation passes.
- [x] CHK005 [Coverage] Does each story map to FR and SC evidence, and are all edge cases assigned to a requirement family? Evidence: Covers fields map US1–US7; identity/retry/hook ordering maps to FR-039–FR-049, retrieval/projection failure to FR-011–FR-030, migration failure to FR-009–FR-010, and metric ambiguity to FR-053–FR-063.
